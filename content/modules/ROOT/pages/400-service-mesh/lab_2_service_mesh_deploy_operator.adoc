== Introduction

In this section you install the operators required for *OpenShift Service Mesh 3* and the Kiali console used later for observation.

[IMPORTANT]
====
Do *not* install *Red Hat OpenShift Service Mesh 2* / Maistra on this cluster.
Service Mesh 2 and Service Mesh 3 conflict unless carefully isolated.
This workshop uses package `servicemeshoperator3` (display name *Red Hat OpenShift Service Mesh 3*).
====

:numbered:
== Service Mesh 3 Operator install

Install these Operators in order and wait for each CSV to reach *Succeeded* before continuing:

* *Red Hat OpenShift Service Mesh 3* (`servicemeshoperator3`) — provides the Sail Operator APIs (`Istio`, `IstioCNI`, `IstioRevision`, …) and installs Istio CRDs.
* *Kiali Operator provided by Red Hat* (`kiali-ossm`) — required for the observe lab. Service Mesh 3 does *not* embed Kiali in the control plane CR the way Service Mesh 2 did.

Optional (not required for this workshop path): Tempo / OpenTelemetry operators for distributed tracing.

=== Operator installation procedure (console)

. Open the OpenShift web console. If you need the URL:
+
[source,sh,role=execute]
----
oc whoami --show-console
----
+
or
+
[source,sh,role=execute]
----
rosa describe cluster --cluster rosa-$GUID --output json | jq -r .console.url
----

. Switch to the *Administrator* perspective.
. Open *Ecosystem* → *Software Catalog* (on some clusters this is still labeled *Operators* → *OperatorHub*).
+
image::operatorhub.png[Software Catalog / OperatorHub]

. Install the Operators *in this order*, one at a time:

* Red Hat OpenShift Service Mesh *3*
* Kiali Operator provided by Red Hat

. For each Operator:
.. Type the Operator name in the filter box and select the *Red Hat* catalog entry (not Community / not Service Mesh 2).
.. Click *Install*.
.. On *Install Operator*, keep:
... *Update channel:* `stable`
... *Installation mode:* All namespaces on the cluster
... *Approval strategy:* Automatic
.. Click *Install* and wait until *Installed Operators* shows *Succeeded* before continuing.
+
image::operatorhub-click-install.png[Operator Install]

. Open *Operators* → *Installed Operators* (Project: `openshift-operators` or *All Projects*) and confirm both Operators are healthy.
+
image::show-installed-operators.png[Installed Operators]

=== Verify from the CLI

[source,sh,role=execute]
----
oc get csv -n openshift-operators
----

You should see Succeeded entries similar to:

[source,text,options=nowrap]
----
NAME                          DISPLAY                            VERSION   PHASE
kiali-operator.v2.27.4        Kiali Operator                     2.27.4    Succeeded
servicemeshoperator3.v3.3.7   Red Hat OpenShift Service Mesh 3   3.3.7     Succeeded
----

Confirm the Sail Operator CRDs exist:

[source,sh,role=execute]
----
oc get crd istios.sailoperator.io istiocnis.sailoperator.io
----

*Congratulations!*

You installed OpenShift Service Mesh 3 and the Kiali Operator. Next you deploy the Istio control plane and CNI.
