== Introduction

Configure weighted traffic between Bookinfo `reviews` versions and observe the mesh with Kiali.

In Service Mesh 3, Kiali is *not* created by the `Istio` CR.
You create a `Kiali` custom resource after installing the Kiali Operator (lab 2).

:numbered:
== Configure weighted load balancing

. Apply a VirtualService that sends 80% of `reviews` traffic to `v1` and 20% to `v2`:
+
[source,sh,role=execute]
----
cat <<'EOF' | oc apply -f -
apiVersion: networking.istio.io/v1
kind: VirtualService
metadata:
  name: reviews
  namespace: bookinfo
spec:
  hosts:
  - reviews
  http:
  - route:
    - destination:
        host: reviews
        subset: v1
      weight: 80
    - destination:
        host: reviews
        subset: v2
      weight: 20
EOF
----
+
.Sample Output
[source,text,options=nowrap]
----
virtualservice.networking.istio.io/reviews created
----
+
[NOTE]
====
Use the full resource name `virtualservice.networking.istio.io` when checking status if your cluster also has VolumeSnapshot short-name conflicts with `vs`.
====

. Refresh the Bookinfo product page several times.
Most responses show reviews without stars (`v1`); some show black stars (`v2`).
+
Recover the OpenShift Route URL with:
+
[source,sh,role=execute]
----
echo "https://$(oc -n bookinfo get route bookinfo -o jsonpath='{.spec.host}')/productpage"
----

== Deploy Kiali and observe traffic

. Enable user-workload metrics scraping used by Kiali against the platform Prometheus stack:
+
[source,sh,role=execute]
----
cat <<'EOF' | oc apply -f -
apiVersion: v1
kind: ConfigMap
metadata:
  name: cluster-monitoring-config
  namespace: openshift-monitoring
data:
  config.yaml: |
    enableUserWorkload: true
EOF
----

. Create the Kiali instance in `istio-system`:
+
[source,sh,role=execute]
----
cat <<'EOF' | oc apply -f -
apiVersion: kiali.io/v1alpha1
kind: Kiali
metadata:
  name: kiali
  namespace: istio-system
spec:
  version: default
  istio_namespace: istio-system
  auth:
    strategy: openshift
  deployment:
    cluster_wide_access: true
  external_services:
    grafana:
      enabled: false
    prometheus:
      auth:
        type: bearer
        use_kiali_token: true
      thanos_proxy:
        enabled: true
      url: https://thanos-querier.openshift-monitoring.svc.cluster.local:9091
    tracing:
      enabled: false
EOF
----

. Wait for Kiali to become ready and print the console URL:
+
[source,sh,role=execute]
----
oc -n istio-system rollout status deploy/kiali --timeout=180s
echo "https://$(oc -n istio-system get route kiali -o jsonpath='{.spec.host}')/console"
----
+
.Sample Output
[source,text,options=nowrap]
----
deployment "kiali" successfully rolled out
https://kiali-istio-system.apps.rosa-<guid>.xxxx.p3.openshiftapps.com/console
----

. Open the Kiali URL and click *Log in with OpenShift*.
+
[subs="attributes"]
====
Use your OpenShift credentials for this cluster (for example the workshop admin user and password provided in the environment).
If you already have an authenticated OpenShift console session in another tab, SSO may skip the login prompt.
====
+
image::kiali-login-with-cluster-credentials.png[Kiali Login]
+
image::verify-overiview-bookinfoapp.png[Kiali Console]

. Generate traffic while you explore the graph:
+
[source,sh,role=execute]
----
while true; do
  curl -k -sS "https://$(oc -n bookinfo get route bookinfo -o jsonpath='{.spec.host}')/productpage" \
    | head -n 5
  sleep 1
done
----
+
Leave the loop running and continue in Kiali.

. In Kiali open *Graph*, select the `bookinfo` namespace, and choose an *App* graph.
+
image::select-bookinfo-from-kiali-dropdown-graph-tab.png[Kiali Console]

. Enable *Display idle nodes* if some services are quiet.
+
image::kiali-click-display-idlenodes-graph-tab.png[Kiali Console]

. Explore display settings and open the *Workloads* view for `details-v1`.
+
image::graph-example.png[Kiali Console]
+
image::example-details-workload.png[Kiali Console]

. Stop traffic generation with kbd:[CTRL+c].

*Congratulations!*

You shifted Bookinfo traffic with a VirtualService and observed the Service Mesh 3 data plane in Kiali.
